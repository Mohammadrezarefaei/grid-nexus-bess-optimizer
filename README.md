Welcome to the Grid-Nexus BESS Optimizer. This repository contains a linear programming tool designed to maximize the economic returns of a Battery Energy Storage System (BESS). By analyzing day ahead electricity market prices, the algorithm determines the most profitable charging and discharging schedule for your battery.

Whether you are a researcher, an energy trader, or an engineer, this application provides an interactive web interface to test different battery parameters and see the financial results instantly.

## ✨ Key Features

* **Interactive Dashboard:** A fully responsive web interface built with Streamlit.
* **Optimization Engine:** Utilizes the robust PuLP library to solve mixed integer linear programming problems quickly.
* **Dynamic Visualization:** Generates beautiful interactive charts using Plotly.
* **Ready for Production:** Includes unit tests and a modular code structure for easy deployment.
